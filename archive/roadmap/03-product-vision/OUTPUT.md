# Fase 3 — Product Vision

## Vision Statement

"**QuantBit adalah command center untuk investor IDX** — bukan broker, bukan sosial media, tapi decision engine yang ngasih lo jawaban jelas: beli apa, kapan jual, dan apakah strategi lo outperform pasar."

## Target User

- **Investor IDX aktif** — udah punya portofolio, butuh alat analisis lebih dalem
- **Trader yang puyeng** broker error pas market buka
- **Multi-broker user** — punya saham di 2-3 broker, pengen unified view
- **Data-driven** — percaya data, bukan feeling

## High-Level Goals (1 Tahun)

1. Decision engine akurat — BPS, ranking, crash detection valid secara statistik
2. 1.000 user aktif bulanan
3. Portfolio tracker lintas broker

## OKRs — Q1 Launch

**O1:** Launch MVP dengan decision engine + backtest
- KR1: Engine accuracy dalam 0.5% dari golden file v1
- KR2: Backtest selesai < 5 detik untuk 5 tahun
- KR3: 10 user beta dengan feedback positif

**O2:** Portfolio tracker
- KR1: Input manual < 2 menit
- KR2: Valuasi akurat dari D1

**O3:** AI assistant
- KR1: AI jawab portfolio dengan structured output
- KR2: Zero regex fallback di production

## Revenue Model

**Freemium:**
- Free: market overview, portfolio (10 holdings), AI (5 msg/bln), backtest (2yr)
- Pro (Rp99rb/bln / Rp799rb/thn): unlimited, full engine, AI unlimited
- Quant (Rp199rb/bln / Rp1.599rb/thn): full backtest, multi-portfolio, priority
